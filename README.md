## Orekit
 
Do działania biblioteki Orekit trzeba dodać folder orekit-data do głównego folderu projektu ($HOME/adastramapper/)

link do pliku zip:

https://gitlab.orekit.org/orekit/orekit-data/-/archive/main/orekit-data-main.zip

Plik należy rozpakować do folderu adastramapper/orekit-data
